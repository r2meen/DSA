## 📖 About

This repository holds my coursework for **CS-220: Data Structures & Algorithms**.
It includes clean, well-commented implementations of core data structures and algorithms, along with complexity analysis, lab assignments, and personal notes as I work through the course.

> Built for learning first — clarity over cleverness.

## 📂 Repository Structure

```
CS-220-DSA/
├── 01-complexity-analysis/     # Big-O, Big-Ω, Big-Θ, empirical vs theoretical
├── 02-arrays-strings/          # Array operations, string algorithms
├── 03-linked-lists/            # Singly, doubly, circular linked lists
├── 04-stacks-queues/           # Stack, queue, deque implementations
├── 05-recursion/               # Recursive algorithms & backtracking
├── 06-trees/                   # BST, AVL, heaps, traversals
├── 07-graphs/                  # BFS, DFS, shortest paths, MST
├── 08-sorting/                 # Merge, quick, heap, radix sort
├── 09-hashing/                 # Hash tables, collision handling
├── labs/                       # Weekly lab assignments
└── notes/                      # Concept summaries & cheat sheets
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/CS-220-DSA.git
cd CS-220-DSA
```

Compile any file (example):

```bash
gcc 03-linked-lists/singly_linked_list.c -o list
./list
```

For C++ files:

```bash
g++ 06-trees/bst.cpp -o bst
./bst
```
